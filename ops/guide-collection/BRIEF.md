## Главное правило

Справочная — не «текст ради объёма» (сайт за это уже отклоняли). Каждый блок пересказывает
ОДНУ официальную страницу, ссылка на неё и дата проверки видны читателю.

- Источник — только официальный сайт аэропорта или официальный сайт оператора услуги
  (транспортная компания города, железная дорога, оператор парковки, сеть отелей, сеть залов).
  Википедия, агрегаторы, блоги, турсайты, отзывы — НЕЛЬЗЯ (можно только как подсказку, где
  искать на официальном сайте).
- Чего нет на странице — нет в блоке. Ничего не додумывать, не обобщать, не советовать.
- Страница противоречит сама себе или другой официальной странице — этот факт не публикуется.
- Каждое число, время, цена, номер маршрута — ровно как на странице. Валюта — как на странице
  (USD $, £, €, ¥, ₩, S$, AED, HK$, ₹, ฿, RM…), без пересчёта в рубли.
- Цены и расписания, которые явно помечены как устаревшие или «до такой-то даты» в прошлом, не
  брать.

## Сбор — только Claude in Chrome

- Только браузер Claude in Chrome (`mcp__claude-in-chrome__*`), в СВОЕЙ новой вкладке
  (`tabs_create_mcp`), чужие вкладки не трогать. Закрыть свою вкладку в конце.
- Один сайт за раз, без всплесков: страницы открывать по одной, не долбить повторно.
- НИКОГДА не обходить защиту от ботов: не решать капчи, не вычислять cookie, не менять
  User-Agent, не ходить в обход JS-проверки. Страница закрыта защитой или не грузится после
  2–3 спокойных попыток — пропустить блок/аэропорт и записать причину в журнал.
- WebFetch, curl и прочие не-браузерные способы НЕ использовать. Если инструментов Chrome у
  тебя нет — остановись и сообщи об этом, ничего не собирая.
- Не нажимать «принять все cookie» без нужды; если баннер мешает читать — «отклонить/только
  необходимые». Ничего не покупать, не логиниться, форм не отправлять.
- Если у сайта есть русская версия — брать её; иначе английскую (или местную, если английской
  нет) и переводить на русский точно, без пересказа.

## Формат файла

```json
{
 "iata": "XXX",
 "checked": "2026-10-25",
 "about": "необязательно: 1–3 предложения с официальной страницы «об аэропорте»",
 "about_url": "https://… (обязательно, если есть about)",
 "blocks": [
  { "id": "transport", "title": "Как доехать", "hint": "…", "text": "…", "source": "домен.без.www", "url": "https://точная/страница" }
 ]
}
```

Блоки (id → заголовок): `transport` → «Как доехать», `taxi` → «Такси», `terminals` →
«Терминалы» (или «Терминал», если он один), `lounges` → «Бизнес-залы», `storage` → «Камера
хранения», `sleep` → «Где поспать», `kids` → «С ребёнком», `parking` → «Парковка», `wifi` →
«Wi‑Fi». Только эти id, каждый не больше одного раза, порядок как в списке. Брать те, для
которых нашлась внятная официальная страница; разумно 4–7 блоков на аэропорт. Блок с одной
пустой фразой («есть парковка») хуже, чем отсутствие блока.

- `hint` — 2–6 слов, суть для плитки: «Метро M11, автобусы Havaist», «От 25 AED, круглосуточно».
- `text` — 2–5 предложений, плотные факты: что, где (терминал, уровень, до/после досмотра),
  когда, сколько, для кого. Без вводных, оценок, эмодзи, «рекомендуем».
- Этажи и уровни — как на указателях этого аэропорта («уровень 1», «Level 3» → «уровень 3»,
  «этаж 2»; если сайт пишет Departures level / Arrivals level — «уровень вылета/прилёта»).
- Названия залов, станций, линий, брендов, сетей Wi‑Fi — латиницей, как на сайте; города и
  районы — общепринятой русской формой в именительном («Синдзюку», «Манхэттен»).
- Возраст «under 2» → «до 2 лет»; «2 and under» → «до 2 лет включительно».
- `source` — домен без www (`changiairport.com`), `url` — точная страница, где факт виден.

## Журнал

Для каждого аэропорта — строка в `ops/guide-collection/log-<твоё имя партии>.md`: официальный
домен, какие блоки собраны, какие нет и почему (нет страницы, защита, противоречие), с какого
языка версии сайта. В конце партии прогнать `node scripts/check-guide-fresh.mjs` — для твоих
файлов провалов быть не должно (провалы «нет перевода» для новых аэропортов ожидаемы: переводов
ещё нет — их игнорируй).

Не запускать git, ничего не трогать вне своих `data/airport-guide/<IATA>.json` и журнала.
