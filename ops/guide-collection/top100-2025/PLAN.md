# Справочная мирового топ-100: охват и очередь

Поручение владельца 26.10.2026: расширить справочную до мирового топ-100 по пассажиропотоку, на всех 12 языках. Справочная остаётся внутри страниц аэропортов; дизайн, DNS и механизм покупки рейсов не меняются. Новая партия не публикуется до отдельного подтверждения.

## Основа списка

Год пассажиропотока — 2025. Полная открытая таблица: [WAIS World Airports Ranking 2025](https://wais.world/267-2/), прочитана обычным Chrome. Это самостоятельный рейтинг WAIS, **не официальный полный топ-100 ACI**. Методика WAIS допускает best-supported/derived/rounded/estimated значения; показатели из рейтинга не добавляются в справочную и на сайт. Список первых 50 аэропортов совпадает по кодам и порядку с текущей таблицей Википедии; официальный ACI на https://aci.aero/resources/busiest-airports-in-the-world/ публикует открыто топ-20, полный набор ведёт в магазин. Покупок нет. Снимок списка — ranking.json.

## Порядок работы

1. Сбор русского оригинала только по официальным страницам аэропорта/оператора, по одной странице в Chrome; исходный текст и решения фиксировать в журнале. Каждый блок — одна страница. Числа/условия/двери/gates/сторона досмотра только по источнику.
2. Повторная проверка каждого утверждения по URL, исключение противоречий и устаревшего. Отдельные журналы сбора и проверки.
3. Все 11 переводов оригинала, ручная сверка каждого блока, межъязыковой проход, выборки ChatGPT по прежним правилам.
4. Сторож, алфавиты/подписи/структура всех новых файлов, tsc/check:scripts, сборка на фикстуре без ключа, проверка HTML/FAQ всех языков, мобильная проверка существующего компонента.
5. Коммит с причиной, fetch/rebase, отчёт владельцу. Без пуша до подтверждения.

Актуальное покрытие и выполненные проверки — в STATUS.md. Этот файл фиксирует основу списка и исходный порядок работы, а не разрешение на публикацию.

На странице остаётся дата проверки; FAQPage повторяет только видимый текст ответа. Это изменение показа, а не отказ от проверки первичных источников.
