## PKX Wi-Fi — пока не подтверждена графическая инструкция

URL https://www.bdia.com.cn/#/servicelist?type=71&childrenid=84 ; `/tmp/airports-top100-batch1/PKX-wifi.txt` содержит 免费WIFI, то есть бесплатный Wi-Fi. Он не содержит SSID, passport, ID Login, выбора типа документа или фотографирования.

`/tmp/airports-top100-batch1/PKX-wifi-note.txt` — заметка коллектора о просмотренной картинке. Это вторичное свидетельство исполнителя, не исходное изображение для независимой сверки. Поэтому независимо подтверждены лишь бесплатный Wi-Fi и наличие соответствующей страницы; имя BDIA-FREE-WiFi, hint «вход по паспорту» и пошаговый вход пока не подтверждены. Это не установленная ошибка, а пробел доказательств. До полного допуска сохранить картинку для проверки либо убрать неподтверждённые SSID/инструкцию из черновика. Картинку не восстанавливать по памяти и заметке.

## CLT parking — факты подтверждены, одна смысловая правка accessibility

URL https://www.cltairport.com/parking/ ; `/tmp/airports-top100-batch1/CLT-parking.txt`.

- 24 hours a day, 365 days a year — круглосуточно круглый год.
- Предбронь и drive-up first come first served — две допустимые категории, не обязательность брони для всех парковок.
- Booked / Reservation Only означает все drive-up spaces текущей парковки заняты, но уже забронировавшие сохраняют доступ. Черновик не объявляет парковку закрытой для всех и не обещает новые места без брони.
- All CLT parking facilities include handicap-accessible spaces with accessible shuttles running continuously — source действительно распространяет оба свойства на все парковки, это не чрезмерное обобщение черновика.
- Valet must be booked at least 3 hours in advance — минимум 3 часа, а не максимум или ровно 3.
- Hint «с бронированием» не устанавливает исключительность брони, поскольку основной текст явно упоминает въезд без неё.

**Нужная смысловая правка:** «непрерывно курсируют доступные шаттлы» → «непрерывно курсируют шаттлы, приспособленные для пассажиров с инвалидностью». Accessible в связке с handicap-accessible parking означает доступность для маломобильных пассажиров, а не просто наличие свободного шаттла. Это уточнение переносит подтверждённое source-условие, нового факта нет.

## JED sleep — подтверждено, одна смысловая правка accessible rooms

URL https://www.myaerotel.com/en-uk/find/middle-east/saudi-arabia/jeddah/aerotel-jeddah ; `/tmp/airports-top100-batch1/JED-sleep.txt`.

- Transit passengers: не проходить arrival immigration; без onward boarding pass вернуться нельзя. В источнике повторный вход также зависит от часов airline check-in. Черновик формулирует наличие boarding pass как необходимое условие, не как достаточную гарантию входа — фактической ошибки нет. При дальнейшем сокращении не превращать это в «с boarding pass всегда можно вернуться».
- 120 rooms; flexible hourly booking. Не вводится минимальная длительность, тариф или бесплатное пребывание.
- Accessible rooms available upon request.

**Нужная смысловая правка:** «доступные номера предоставляются по запросу» → «номера для маломобильных гостей предоставляются по запросу» (либо «номера, приспособленные для гостей с инвалидностью»). Сейчас русская фраза читается как наличие свободных номеров, тогда как источник сообщает специальную доступность.

Это отдельные уточнения, но черновик не обещает безусловный вход с улицы в любое время и не описывает online-условия, поэтому не считаются искажением опубликованных фактов. Править сверх выбранного состава не требуется.
