## Принятые поправки и состояние копий

Проверяющий прочитал текущие файлы, а не только сообщение основного исполнителя:

1. `drafts/JED.json`: «доступные номера» → «номера для гостей с ограниченной подвижностью». Условие upon request сохранено. Fenced JSON также содержит исправленный смысл («номера для маломобильных гостей»), эквивалентно.
2. `drafts/CLT.json`: «доступные шаттлы» → «шаттлы, приспособленные для пассажиров с инвалидностью». **В `research-batch1.md` на момент этой сверки старая фраза ещё присутствует.** Перед извлечением единого набора JSON нужно синхронизировать этот блок с исправленным draft; иначе утверждение «все 27 финальных блоков исправлены» было бы неточным.
3. `drafts/BOM.json`: «в направлении двери A» → «в направлении Gate A». Это устраняет непроверенную буквальность Door при сохранении исходного ориентира arrivals, не boarding. В MD могла оставаться старая формулировка; при переносе использовать исправленный draft.
4. FCO kids в MD: восстановлено условие сдачи своей коляски при регистрации. Повторно проверено выше.
5. Неполные снимки ATL/BOM/CGK пересохранены полным DOM; PKX Wi-Fi получил три исходных PNG. Это исправление доказательств, не фактов. Первоначальные статусы «не проверено» сняты только после чтения новых доказательств.
