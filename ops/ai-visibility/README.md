# Замер видимости в ИИ-ответах

Повторяемый замер того, называют ли ИИ-поисковики airportsboard.live источником по русским
запросам. Метод взят из скиллов `ai-seo:brand-monitoring-ai-visibility-report` и
`seo-aeo-geo-ultimate:ai-visibility-monitor`, но без их тяжёлой обвязки (60 строк корпуса на
4 движка, SHA-256 на каждый снимок): у сайта один владелец, и проще держать честный JSON.

## Файлы

- `corpus-ru-v1.json` — **замороженный** корпус: 15 запросов, целевая страница у каждого.
  Тексты не править. Правка запроса = новый корпус (`ru-v2`) и новая база; сравнивать прогоны
  можно только внутри одного корпуса.
- `run-YYYY-MM-DD*.json` — прогоны. `run-2026-10-25-pilot.json` — пилот: корпус заморожен
  после замера, повторов не было, поэтому `comparable_baseline: false`. Первая настоящая база —
  следующий прогон.
- `summarize.mjs` — сводка по прогону и сравнение двух прогонов.

## Что меряем

Бренд airportsboard никто не ищет, поэтому «упоминание бренда» из скиллов нам ничего не даёт.
Меряем три вещи:

| поле | смысл |
|---|---|
| `ours_in_sources` | наш домен в списке источников ответа |
| `ours_in_text` | ответ прямо называет сайт или ссылается на нашу страницу в тексте |
| `sources` | все видимые хосты-источники — отсюда «кого цитируют вместо нас» |

Знаменатель — только прогоны со `status: "observed"`. `unavailable` (ИИ-блок не показан),
`blocked` (капча) и `inaccessible` (нет квоты) в знаменатель не входят и считаются отдельно.

## Как прогонять (раз в месяц, ~1 час)

Claude in Chrome под логинами владельца. Для каждого запроса × движок — **новый чат**, по
ссылкам в ответах не кликать (особенно на наш сайт — это покупка данных). Капча → `blocked`,
не обходить.

- **Perplexity:** `https://www.perplexity.ai/search?q=<запрос>`, дождаться «Завершено», открыть
  «N источников», собрать хосты.
- **Google «Обзор от ИИ»:** `https://www.google.com/search?hl=ru&q=<запрос>`; блок «Обзор от ИИ»
  есть не всегда — нет блока → `unavailable`.
- **Алиса AI:** выдача `https://ya.ru/search/?text=<запрос>`, затем вкладка «Алиса AI» (прямая
  ссылка без `reqid` открывает пустой чат). Хосты источников видны текстом под абзацами.
  Попутно записать позицию сайта в органике (`organic_pos_ours`).
- **Gemini:** `gemini.google.com/app`, ввести запрос; по 3–5 запросам, не по всем.
- **ChatGPT:** только если у владельца есть квота — спросить.

Два повтора на ячейку в разные дни — иначе разницу в один-два ответа не отличить от шума
(скилл brand-monitoring прямо ставит порог: меньше 30 наблюдений на движок — «watch: small
sample», а не вывод).

## Чего этот замер не говорит

Один ответ ИИ — выборка из распределения; позиции и состав источников плавают от прогона к
прогону. Изменение между двумя прогонами — наблюдаемый дрейф, а не следствие правки на сайте:
причинных выводов отсюда не делать.
