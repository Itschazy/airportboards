# Решения по пяти рекомендациям Bing — 30.10.2026

1. **Длинные titles (44)**: прочитаны обе страницы отчёта: 40 EN + 4 RU. Отдельный server-only helper сокращает только длинные метаданные parent/arrivals. EN: классификационные International/Regional, затем Airport, в крайнем случае Live; собственное имя/город/IATA/направления сохраняются. RU: «Онлайн-табло аэропорта» → «Табло». Другие 10 языков, короткие titles и специальные состояния closed/no-service/info не меняются. H1 и Airport entity неизменны. Полный проход по 44 URL на свежей синтетической фикстуре — в артефактах; это не подтверждение переобхода Bing.
2. **IndexNow (6)**: три /departures — canonical-дубли, не отправляем. MEL-PER/en, BER-AYT/de, BRS-PMI/en: HTTP200/index/selfcanonical в исходном аудите; дополнительный curl audit-bot по всем дочерним sitemap подтвердил отсутствие. Причина в отборе top-routes по рейсам/top-8, а не по поисковому спросу. Добавлены три кандидата спроса; getRoute.length>0 остаётся обязательным, 12 языков одной группы. Discovery берёт только итоговый sitemap. Приоритет только трём наблюдавшимся языковым URL. Нет массовой генерации направлений или принудительного index пустого маршрута.
3. **Описания (466)**: в доступной выборке25 большинство CJK, также IT; содержательные описания не растягиваем до150–160 латинских символов. Недостающих meta description исходный аудит не обнаружил. Полная лингвистическая рецензия всех466 не заявляется. В этот пакет текст описаний не входит.
4. **Batch**: транспорт уже100URL/10мин, партия50, fallback/backoff и publication guard. Не меняем работающий таймер. Исправлен отдельный пропуск fingerprint messages.meta и нового title-helper; тест проверяет изоляцию EN/DE. Полное развёртывание может разово обновить fingerprints аэропортов из-за изменения источника; это содержательный пакет, не ежедневная переотправка.
5. **Backlinks**: живой профиль3домена/6страниц, план и неотправленный черновик LINKS.md. Изменением кода внешние редакционные ссылки создать нельзя. Покупок и рассылок нет.

Все изменения только в своей ветке поверх origin/main70311dd4. Публикация требует подтверждения владельца. Дизайн/DNS не менялись; платные flights/cron API не вызывались.
