# Улучшения по Метрике — 03.11.2026

## Реализовано

- Карта: пустое поле сразу предлагает существующий локализованный набор и недавние аэропорты. Выбор отправления переводит фокус к назначению. Полный словарь не нужен для начальных подсказок; дизайн прежний.
- Исправлен воспроизведённый сбой: если после загрузки runtime не загрузился каталог, сообщение раньше оставалось скрытым, а кнопка добавления — активной и бесполезной. Теперь видны ошибка и повтор, недоступные кнопки выключены. Регрессия сначала падала, после исправления проходит.
- Воронка карты: параметры визита Метрики для ru, GA4 flight_map_step для всех языков; allowlist этапов, версия выката. Без поисковых фраз, номеров, маршрутов, дат и файлов. Без новых целей, notBounce и правки аккаунтов.
- FAQ аэропортов раскрывается нативно, не ожидая гидратации React. Ответы сохранены в HTML и FAQPage. В вопросе об отсутствующем рейсе добавлен контекстный переход на прилёты/вылеты на всех 12 языках.
- Формат PNG 4:5 теперь входит в allowlist существующей аналитики экспорта.

## Как интерпретировать новую воронку

entry — вход в раздел через нижнюю панель; сохранённый адрес раздела может вести на справку. loading/ready — загрузка именно инструмента. first_saved — успешное добавление в пустую личную историю, не импорт/редактирование; не означает первого сохранения за всю жизнь человека. Этапы дедуплицируются на текущем монтировании, параметры Метрики агрегируются по визиту. download — нажатие, share_resolved — завершение Web Share, не факт публикации. Старую цель saved не переопределяли.

Эффект оценивать после накопления 7 полных дней, сопоставляя мобильный поиск ru и те же аэропорты/браузеры. Воронку считать по визитам, не по сумме повторных событий. Разделять версии выката.
