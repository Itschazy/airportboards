## Проверки и найденные дефекты UI

JSON keys/placeholders и баланс bidi-изоляторов — PASS для 6 × 2 каталогов. Числа сверены по смыслу: у японского три корректных расхождения с механическим regex (1行に1つ, 2つのフライト, 1つのフライト соответствуют русским словам «по одному», «два», «перелёт»).

Read-only review актуального `public/flight-map/v9/app.js`:

1. P1: обратный/следующий перелёт из demo сохраняет isDemo=true, новый пользовательский маршрут исчезнет после reload. Требуется переключение в personal с сохранением выбранных аэропортов.
2. P2: подтверждение импорта ожидает Web Lock без проверки revision после await; можно закрыть окно, открыть новое, затем старый promise закроет новое и очистит новый ввод. Нужно отличать завершившуюся транзакцию от актуального UI, не применять её закрытие к другой форме.
3. P2: undo не очищает period, если в выбранном году больше нет перелётов. Надпись «Все» и пустой журнал могут расходиться с фактическим фильтром.
4. P2: поиск журнала обещает аэропорт, но ищет только в code/city/number, без name. Поиск Heathrow/Sheremetyevo не найдёт соответствующие записи.

Передано parent для исправления. Проверки закрытия sheet, клавиатуры и геометрии на реальном браузере выполняет parent; этот проход не выдаётся за мобильный UI-test.
