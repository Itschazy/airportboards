## Ограничения интерпретации

Только свежий transferSize>0, без service worker, h2/http1.1, конечные согласованные
отметки, непустой connect, secureConnectionStart>0. Иначе tls=-1 (неизвестно).
HTTP/3 исключён: транспорт и защита QUIC не разделяются как TCP/TLS.
Повторное соединение, cache и отсутствующее API не выдаются за нулевой handshake.
Нулевой известный TLS возможен при округлении часов. Длительность connect
не меняется. Остаток connect-tls вычисляется только внутри одной записи и не
объявляется точным TCP RTT; в нём возможны прокси/округление/особенности браузера.
Источник определения полей: https://www.w3.org/TR/resource-timing/ .

Схема v1 расширена необязательным числом, старые вкладки и журналы совместимы.
Отчёты не учитывают -1 как ноль. Анализатор отдельно считает unknown/invalid и
пары TLS/connect, с проверкой согласованности браузерных фаз. Нет вычитания p75.
