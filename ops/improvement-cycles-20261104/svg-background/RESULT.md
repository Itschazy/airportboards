## Причина и изменение

В прошлой трассе SVG-фон имел отдельный документ из 11209 элементов и тратил
около 0.5 с на пересчёт стилей. Это происходило после LCP: не объявляем SVG
причиной всего медленного первого экрана.

Генератор оборачивал каждое определение path в группу только ради translate.
Перенесли неизменённый transform на сам path. Из 3512 экземпляров use исчезает
лишняя группа; вместе с 53 определениями — 3565 элементов. Цвета, координаты,
штрихи, прозрачность, CSS и вёрстка не меняются. До изменения запуск копии
генератора воспроизвёл оба исходных файла байт в байт; новый генератор точно
воспроизвёл экспериментальный вариант.
