## Найденные недоработки и приоритет

1. **P1 — незакрытая проверка совместимости.** Требуются физические iPhone/Safari и Android/Chrome с установленными приложениями. Проверить редактор, получение файла, изображение после сжатия, выбранный формат, отмену и повторную отправку. Отдельно Яндекс Браузер, отсутствие приложения, запрет разрешений. Это проверочный пробел, не найденный сбой загрузки.
2. **P2 — формат по умолчанию9:16 не универсален.** X документирует полное отображение одиночных фото в диапазоне2:1…3:4. Наши1:1 и4:5 подходят,9:16 выходит за диапазон и может обрезаться в ленте. Рекомендация: явно объяснить «сторис»/«пост», не обещать универсальный формат; для ленты предлагать4:5/1:1, для сторис9:16. Автоматически менять файл по значку рискованно: реального получателя всё равно выбирает пользователь в меню.
3. **P2 — неточная ошибка m126.** public/flight-map/v9/app.js:sendImage при любой async-ошибке кроме AbortError пишет «Приложение не приняло картинку». В Chrome при автоматизированном клике меню ещё не открылось, но выводится эта фраза. Причина может быть в браузере/разрешении/активации, а не приложении. Предлагается нейтральное «Не удалось передать картинку. Сохраните PNG и прикрепите вручную» на12языках.
4. **P2 — два шага для подписи.** PNG передаётся без text/url, подпись копируется отдельно. Это намеренная совместимость: смешанный payload некоторые получатели обрабатывают как ссылку. Не обещать автоматическую подпись; в подсказке объяснять сохранениеPNG и отдельную вставку. ClipboardChrome требует нативного повторного контроля.
5. **P3 — итоговый вид зависит от соцсети.** Лого/подписи внутри PNG проверены на выборке; UI сторис, safe areas, наложение имени аккаунта и кнопок ещё не проверены. ШрифтыCJK/AR/HI на macOS выглядят корректно; это не доказательство соответствующего рендера на слабомAndroid.

Не подменять PNG ссылкой на /flight-map: ссылка открывает сервис, а не личную историю. Не добавлять выдуманные URI с передачей локальногоblob. Не считать resolve navigator.share подтверждением публикации. Не загружать личные маршруты на сервер только ради выбора соцсети.
