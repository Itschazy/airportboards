# Bing: пакет после аудита 29.10.2026

Исходные данные — outputs/bing-audit-20261029 в папке чата. CSV содержит только 25–26 октября; сегодняшний выкат по ним не оцениваем.

1. IndexNow: сохраняем очередь вне checkout, отслеживаем изменения содержимого, отправляем до 100 URL за запуск партиями по 50; повторяем только непринятые партии. Блокировка, атомарная запись, ограничение повторов и проверка опубликованного SHA обязательны. Старый daily-вызов сохраняется для discovery; отдельный worker каждые 10 минут подключается при выкате. Сборка и dry-run ничего не отправляют.
2. EDI/LBA/NCL/GLA/DMM: факты только с официальных страниц через обычный Chrome, русский оригинал → 11 переводов, проверка условий/чисел/названий и SSR.
3. FAQ arrivals: ответы встречающим раньше технических кодов; советы о вылете остаются на вылетах. Видимый текст и FAQPage из одного массива.
4. MAN/LHR: замороженный baseline и проверка нынешних метаданных; не менять повторно заголовки до появления данных после переобхода.
5. Внешние упоминания: проверенные подходящие площадки и адресные черновики. Никаких покупок и отправки от имени владельца.
6. Проверки: очередь при частичном отказе/перезапуске, tsc, ключи/ICU/алфавиты, сторож справочных, fixture build, SSR 5×12×2, mobile 375/RTL, прежние SEO/board guards. Затем итоговый пакет для владельца; без переноса исторических согласий на новый выкат.
