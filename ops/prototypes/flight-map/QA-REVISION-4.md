# Редакция 4 — сохранение, резервная копия, карта (28.10.2026)

Только локальный статический прототип. Проверки относятся к собственной ветке
codex/flight-map-prototype-20261028, а не к production. Изменений Next-приложения нет.

## Реализовано

- Версионированное on-device сохранение в отдельном ключе localStorage, стабильные ID.
  UI сообщает об успехе только после записи. Демо хранится отдельно и не экспортируется.
- JSON backup, лимит файла 2 МБ/5000 записей; проверка схемы, ID, аэропортов, реальных дат,
  неизвестной версии, типов полей. Невалидный файл отклоняется целиком.
- Предпросмотр восстановления с количествами новых/совпадающих/конфликтующих записей.
  Объединение по ID; текущие записи при конфликте остаются. Повторный импорт идемпотентен.
- Повреждённое локальное сохранение не перезаписывается; можно скачать исходный файл.
  Последовательная запись из другой вкладки обнаруживается до сохранения старой формы.
- Mercator + Natural Earth50m, offline simplification:22661 точка,382944 байта.
  Города+IATA, размещение подписей без наложения друг на друга, контур берега/маршруты.
  Береговая геометрия задаётся один раз и переиспользуется SVG use в трёх копиях мира.
  Источник: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_land.geojson
  Public domain: https://www.naturalearthdata.com/about/terms-of-use/

## Ограничения

Это Chrome с мобильными размерами, не физические Safari/Яндекс/Android.
LAN-сервер: http://192.168.31.98:3103/ru/my-flights-prototype/ — одна Wi-Fi-сеть с Mac.
Данные привязаны к origin; очистка браузера удаляет местную копию, нужен внешний backup.
Нет облачной синхронизации. LocalStorage не транзакционен между вкладками при строго
одновременной записи: production-перенос требует IndexedDB. Массовый рендер5000 строк
на слабом устройстве не измерен (проверено только отсутствие overflow стека в fit).
Русский локальный прототип; переводы новой функции ещё не интегрировались в приложение.
