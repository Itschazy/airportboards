# Поиск карты v8 — 29.10.2026

## Причина и решение

V7 дожидалась дополнительных английских алиасов даже для «Челя» из уже загруженного русского каталога. Минимальное воспроизведение: `createDeferredSearch(core, 'ru', () => new Promise(() => {})).query('Челя')` не завершалось. Новый тест сначала упал, затем прошёл.

V8 строит небольшой локальный индекс city/name/code сразу после core, независимо от географии и английских алиасов. Локальные подсказки возвращаются синхронно. Если совпадений нет, запрос ждёт полного индекса; ошибка сети допускает повтор. Фоновое дополнение не перерисовывает открытый список. Полный индекс сохраняет прежнее ранжирование, нормализацию/диакритики и транслитерацию. Повторная нормализация одинаковых строк убрана; полный индекс по-прежнему уступает main thread через MessageChannel.

На CPU6× простое разделение загрузки оказалось недостаточным: очередь подготовки полного core-индекса занимала ещё ~1,6с. Промежуточная оптимизация кэша/порций снизила задержку, но только отдельный короткий локальный индекс позволил искать к моменту открытия карты. Это не объявление полной готовности английских алиасов.

Быстрый сценарий сохранения→шейринга выявил гонку dialog.close/close/popstate. Новый контроллер дожидается снятия записи формы из history перед открытием следующего окна и запуском экспорта. Добавлены регрессии очереди, нативного закрытия, Back, abort и перехода к восстановлению.

## Методика

Локальная fixture build без ключа Airlabs. Прод в браузере не открывался. Сравнение старой `.next-v7-release` и новой сборки, один Chrome, viewport320×667, CPU6×. Сеть ограничена собственным QA proxy: общий бюджет150000Б/с (1,2Мбит/с), задержка500мс, gzip, cache-control:no-store. Это отличается от прошлой DevTools Slow4G, поэтому сравнивать абсолютные числа с прошлым отчётом напрямую нельзя. В обоих вариантах одинаковые ограничения. Это лаборатория desktop Chrome, а не физический Android или RUM.

Для LCP/CLS используются только чистые загрузки без открытия форм/экспорта. Flow-прогоны предназначены для задержек взаимодействий и не характеризуют LCP первого экрана. LCP здесь — заголовок, а не SVG-карта. Исключён агентский курсор-оверлей.

Первые попытки через iframe Chrome не завершились и не учитывались. В Safari iframe375px работал. Часть native-действий DevTools не применялась; CPU6× и ширина320 подтверждены AX/DOM, сеть ограничена серверным proxy. Профильные настройки после работы должны быть восстановлены.
