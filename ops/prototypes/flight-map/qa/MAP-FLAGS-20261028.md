Параллельная задача пользователя: добавить красивые флаги стран, убрать фразу
«А как выглядит твоя карта», сделать карту современнее. Рабочая копия:

## Реализация

- Флаги в один центрированный ряд под статистикой: 4:3, скругление 5 px,
  тонкая обводка, ширина 72 px (64 px при 7–9 флагах) на PNG 1080 px.
  Максимум девять, затем `+N`; нет неразличимой сетки из сотни флагов.
- Страны берутся только из аэропортов выбранной карты/года/рейса. Подпись
  «на карте» сохранена: наличие аэропорта не доказывает выход из транзита.
  Неизвестный пустой ISO-код больше не считается отдельной страной.
- Убраны обе приглашающие фразы, в том числе «Куда полетим дальше?», из PNG
  и копируемой подписи. Остаются фактическая статистика и адрес инструмента.
- Изображения — настоящие локальные SVG-флаги. Не emoji, не AI-рисунок,
  не внешний флаговый API. При экспорте загружаются только видимые, до девяти.
  У запросов таймаут 2,5 с; при ошибке вместо выдуманного флага показывается
  двухбуквенный ISO-код. Повторный экспорт может повторить неуспешный запрос.
- SVG встраиваются в PNG как векторы; внутренние ID получают префикс страны.
  Это предотвращает столкновение clipPath/градиентов соседних флагов.
- В географии сохранён Natural Earth 50m, корректные великие круги и
  разворачивание Тихого океана. Добавлены тонкие сухопутные границы,
  чтобы материки не выглядели бесформенным пятном. Снята широкая тёмная дымка
  сверху/снизу экспорта; осталось короткое затухание на краях. Синий маршрут,
  Inter и существующая айдентика сохранены. Лимит 18 подписей и кэш дуг512
  не изменены. Нет WebGL, новых картографических библиотек, тайлов или API.

Сохранён прежний берег50m. Границы взяты из первичного

Это справочные de facto границы набора Natural Earth, не отдельное заявление
сайта о статусе территорий. Границы по своей природе могут быть спорными.

SHA256 полученного GeoJSON:
`2faac4f6b34386f3d21b6e018cf151f241f00e5c936d44dd17d7d9bfb147fa48`.
393 линии упрощены офлайн Douglas–Peucker с допуском 0,045 градуса, координаты
округлены до 3 знаков: 5416 точек. Нет скачков долготы больше 180°.

цена дополнительных ориентиров, не заявленное ускорение географии.

Для обновления: получить тот же GeoJSON с официального репозитория, разбить

координаты до3знаков. Записать `{land:<прежний массив>,borders:<линии>}`

## Совместимость выката

`land.json` оставлен побайтно прежним; новые данные — `land-v2.json`.
createMap принимает прежний массив и новый объект. По согласованию с главным
агентом новый runtime переносится в `/flight-map/v2/`, а старые v1 JS остаются
прежними. Это необходимо: старый app ожидает синхронный `exporter.build`, новый
делает await для выбранных флагов. Открытая до выката SPA не должна смешать
старую оболочку и новый модуль. Новый buildCard остаётся синхронным и чистым.
Данные флагов и land-v2 находятся в v1 по новым, ранее не существовавшим URL.
Результат переноса/деплоя проверяет основной агент.
