# Быстрое добавление и отправка карты — 28.10.2026

База 229bc311, ветка codex/flight-map-prototype-20261028. Новая версия до публикации.

## Что изменено и почему
- Локальный поиск по 6074 аэропортам: коды, города, транслитерация; без debounce/сетевого запроса на каждую букву. Недавние аэропорты из личной истории.
- Вставка пары CEK–AYT, повтор/обратный маршрут без копирования даты и номера. Сохранить и добавить ещё начинает следующий перелёт с аэропорта прибытия.
- Защита от двойного нажатия до await записи; прежние данные и резервные копии совместимы.
- Исправлено исчезновение первого нажатия: очистка подсказок на pointerdown сдвигала кнопку перед click. Теперь обработчик использует исходный composedPath click.
- PNG готовится до нажатия; Web Share получает только файл и title, без смешивания с URL. Ссылка на сервис отправляется отдельно (Telegram, MAX, WhatsApp, X; остальные приложения через ОС). Подпись можно скопировать отдельно. Пользователь сам выбирает получателя и подтверждает отправку.
- Instagram/Facebook нельзя принудительно открыть с PNG/Stories из обычного сайта: показываем системное меню и понятный запасной путь через сохранённую картинку. Не добавлены SDK, загрузка личных маршрутов или платные запросы.
- Флаги, границы, отсутствие CTA: MAP-FLAGS-20261028.md. Исправлен найденный браузером дефект: при встраивании флага AR терялся xmlns:xlink, из-за чего Image.decode отклонял SVG. Namespace сохранён; сценарии 200 маршрутов и девяти сложных гербов теперь проходят.
- Новый runtime /flight-map/v2/ развёртывается вместе с новой оболочкой. v1 app/map/share/land побайтно прежние для старого ISR и открытых вкладок.
