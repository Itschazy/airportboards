# Полный поиск карты v9 — 29.10.2026

## Результат и границы
Полный каталог 6074 аэропортов на всех 12 языках передаётся одним Brotli-модулем. Объём словаря уменьшился на 17,3–21,7% относительно gzip core+aliases v8 (RU 194746 → 159952 байта). География: 85784 → 75471 байт. HTTP modulepreload и import используют общий модульный кэш браузера: в финальной Safari/Chrome записи каждый из двух ресурсов загружался один раз, JSON fallback не вызывался.

Это измеримое сокращение трафика и исправление полноты поиска, но не достижение загрузки быстрее 4 секунд. В строгой локальной лаборатории полный поиск ещё около 5,3 секунды. В v8 локальное имя могло появиться раньше полного словаря; v9 ждёт полный индекс для текста, чтобы не показывать неполную выдачу (например, Paris только в Техасе без CDG). Поэтому нельзя объявлять ускоренными все запросы или сравнивать готовность полного индекса с прежними 4,2 секунды локального поиска. IATA, недавние и популярные аэропорты доступны без ожидания индекса.

## Что исправлено
- Однопроходное декодирование без промежуточного core+aliases массива; ASCII fast path нормализации с сохранением Unicode-семантики. Индекс строится порциями с уступкой event loop.
- Paris в итальянском поиске теперь включает CDG и сохраняет прежнее полное ранжирование. Фоновая неполная выдача больше не остаётся окончательной.
- Safari дублировала незавершённый fetch-preload. Отказались от него в пользу modulepreload/import, проверили фактические запросы. При ошибке модуля остаются Brotli JSON и обычный JSON; отменённая операция не запускает fallback и не монтирует старую страницу.
- Escape закрывает диалог через существующий history-контроллер; последующее открытие шейринга не попадает под устаревшее событие закрытия.
- Старые v1–v8 immutable не изменены. Формат истории, тексты/метаданные/JSON-LD, дизайн других страниц и DNS сохранены.

## Отклонённые эксперименты
Fetch-preload дал дубль в Safari; независимая догрузка географии не улучшила итог карты; раздельные core/aliases модули не дали убедительного выигрыша. Они не вошли в финальную версию. Дальнейший резерв: отделить стоимость поиска/карты на главном потоке, проверить worker либо более компактный индекс отдельным измеримым изменением.
