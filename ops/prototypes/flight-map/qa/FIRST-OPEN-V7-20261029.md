## Причины задержки и изменения

- Полный RU-каталог блокировал карту: 213182 Б gzip. V7 грузит core (имена, коды, страны и точные координаты) 125408 Б; дополнительные поисковые алиасы — 69375 Б с пониженным приоритетом. Сумма меньше старого каталога. Все6074 аэропорта и все12языков сохранены.
- Готовые данные ещё ждали общую гидратацию Next. SSR запускает отдельный DOM-остров через ESM; React принимает существующий lifecycle. WeakMap не допускает двойной mount, abort закрывает listeners/запросы при уходе, ранние категориальные события передаются в обычный allowlist аналитики.
- Индекс разбит на160строк за задачу. Первая реализация через setTimeout(0) оказалась непригодна для Safari: после28с диагностический progress1600/6074, fetch уже parsed, mount1, abort0. Замена на MessageChannel сохраняет уступки main thread, закрывает порты при завершении/abort.
- До готовности текстового поиска сразу доступны недавние аэропорты, точные IATA и вставка CEK–AYT. Текстовый запрос показывает переведённое ожидание, при сетевой ошибке — повторную попытку. Старый ответ не открывает закрытую форму и не подменяет новый запрос.
- В журнале из500перелётов миллионы километров выступали за колонку на320px. Только не помещающееся число подстраивается под фактическую ширину; обычные значения и остальной дизайн прежние.
