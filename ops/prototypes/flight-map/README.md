# Локальный прототип «Мои перелёты» — редакция 3

Только локальное согласование. Production-код, DNS, SEO и платные данные не менялись.
Сохраняется существующая дизайн-система e904f92e: Inter, шапка, фон, стекло и навигация.

## Запуск

Из корня собственной рабочей копии:

```sh
python3 -m http.server 3102 --bind 127.0.0.1 --directory ops/prototypes/flight-map
```

http://localhost:3102/ru/my-flights-prototype/ — пустая карта, добавление первого перелёта.
Добавить `?demo` — пример из 6 перелётов. Переключение примера не уничтожает свои
записи текущей сессии. Обновление страницы сбрасывает все изменения: это прототип,
без аккаунта и постоянного сохранения.

Для проверки с телефона в одной Wi-Fi-сети запущен отдельный сервер, только на
локальном адресе Mac (адрес может измениться):

```sh
python3 -m http.server 3103 --bind 192.168.31.98 --directory ops/prototypes/flight-map
```

http://192.168.31.98:3103/ru/my-flights-prototype/

Это не публичная ссылка и не туннель. Mac должен быть включён; телефон — в той же сети.
В HTTP по LAN Web Share/clipboard обычно недоступны: есть скачивание PNG и ручное
копирование подписи. Не отключать защиту браузера ради доступа. Физический телефон
владельца проверяет сам; Chrome viewport не равен Safari на iPhone.

## Что работает

- Пустое состояние, локальный поиск по 6074 аэропортам, необязательные дата/номер;
  дата будущего перелёта не принимается. Раскрываем дополнительные поля по желанию.
- Добавление, изменение, удаление/отмена; год из фактической истории, выделение маршрута.
- Геодезическая схема, расстояние между аэропортами, учтён переход через 180-й меридиан;
  полный экран с перетаскиванием, zoom, fit и закрытием. Back закрывает модальное окно.
- Карточки «Вся карта / Итоги года / Перелёт», форматы 1080×1920 и 1080×1080,
  тёмная/светлая темы, настоящий PNG с Inter, предпросмотр самого PNG.
- Системное меню отправки файла там, где браузер поддерживает; скачивание в остальных.
  Копируемая подпись с ручным fallback. Никаких автоматических сообщений или публикаций.
- Пример явно отмечен в изображении. Личных полей, точных дат и номеров в экспорте нет.

## Ограничения перед production

Русский изолированный стенд; 12 переводов, постоянное сохранение/backup/импорт,
реальная доступность на физических телефонах и точный мобильный бюджет ещё впереди.
Остальные пункты навигации — заглушки. Геодезическая схема не фактический трек рейса;
страны на карте не означают факт въезда. При почти противоположных аэропортах
на сфере нужна дополнительная продуктовая обработка неоднозначного маршрута.

Данные аэропортов — каталог проекта; сохраняются русские подписи из предыдущей
демовыборки, остальные названия — из каталога. Natural Earth110m — public domain:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
