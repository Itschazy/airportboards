AirportsBoard 비행 지도는 브라우저에서 무료로 사용하는 개인 탑승 기록 도구입니다. 출발·도착 공항을 직접 추가하면 경로, 비행 횟수, 공항 간의 대략적인 거리를 볼 수 있습니다.

비행 지도 만드는 방법

  1. “비행 추가”를 선택하고 도시, 공항 이름 또는 IATA 코드로 두 공항을 찾으세요.
  2. 기억나는 날짜와 항공편명을 입력하세요. 두 항목 모두 생략할 수 있습니다.
  3. 전체 기록을 보거나 연도별로 확인하세요. 공유용 PNG 이미지와 기록 복원용 JSON 백업을 저장할 수 있습니다.

비행 지도 관련 질문

비행 지도는 무료인가요?

네. 결제나 가입 없이 비행 기록을 추가하고 이미지를 저장할 수 있습니다.

페이지를 새로고침해도 기록이 남나요?

같은 브라우저에서 같은 주소를 열면 남아 있습니다. 브라우저 데이터를 지우면 로컬 기록도 삭제됩니다. 기기 간 자동 동기화는 없습니다.

다른 휴대전화로 기록을 옮기려면 어떻게 하나요?

“저장 및 백업”에서 JSON 파일을 저장한 뒤 다른 기기에서 복원하세요. 추가 전에 미리보기가 표시됩니다. 같은 기록은 중복 추가되지 않으며, 충돌하는 기록은 현재 기록을 덮어쓰지 않습니다.

항공기를 실시간으로 추적하는 지도인가요?

아니요. 직접 입력한 과거 비행을 보여 줍니다. 항공기를 추적하거나 이메일에서 탑승 기록을 가져오지 않습니다.

거리와 국가 수는 어떻게 계산하나요?

거리는 구면 위에서 두 공항을 잇는 최단 경로의 추정치이며 실제 비행 경로가 아닙니다. 국가 수는 지도에 표시된 공항이 속한 국가를 세며, 해당 국가에 입국했다는 뜻은 아닙니다.

공유할 이미지에는 무엇이 표시되나요?

경로, 도시, 공항 코드와 통계가 표시됩니다. PNG에는 정확한 날짜나 항공편명이 나오지 않습니다. JSON 백업에는 입력한 날짜와 항공편명을 포함한 기록이 담깁니다.
