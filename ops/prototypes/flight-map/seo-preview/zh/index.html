关于飞行地图

AirportsBoard 飞行地图是可在浏览器中免费使用的个人飞行记录工具。手动添加出发和到达机场，即可查看航线、飞行次数和机场之间的大致距离。

如何制作飞行地图

  1. 选择“添加航班”，按城市、机场名称或 IATA 代码查找两个机场。
  2. 如果记得日期和航班号，可以填写；这两项都可以留空。
  3. 查看全部飞行记录，或按年份筛选。保存 PNG 图片用于分享，保存 JSON 备份用于恢复记录。

飞行地图常见问题

飞行地图免费吗？

是的。无需付费或注册，即可添加飞行记录并保存图片。

刷新页面后，飞行记录还在吗？

在同一浏览器中打开同一地址，记录仍会保留。清除浏览器数据会删除本地记录。目前没有跨设备自动同步功能。

如何把记录转到另一部手机？

打开“保存与备份”，保存 JSON 文件，然后在另一台设备上恢复。添加前会显示预览。相同记录不会重复添加；有冲突的记录不会覆盖现有记录。

这是实时飞机追踪地图吗？

不是。地图显示您手动输入的已完成飞行，不会追踪飞机，也不会从电子邮件中导入飞行记录。

距离和国家数量如何计算？

距离是机场之间沿球面最短路径的估算值，并非飞机实际航迹。国家数量统计的是地图上机场所在的国家，不代表您曾入境这些国家。

分享的图片会显示什么？

航线、城市、机场代码和统计信息。PNG 不显示具体日期和航班号。JSON 备份包含飞行记录，以及您填写的日期和航班号。
