## Реализовано

- Вместо постоянного hash(path + discovered) — версии содержимого для известных sitemap URL: главная, каталоги аэропортов/стран/городов/A–Z, маршруты, виджеты и RU/EN служебные страницы.
- Файлы и JSON читаются/разбираются один раз; digest источников общий для семейства и языка. Нет сериализации всего справочника для каждого из тысяч URL.
- Только статические исходники/редакционные данные и переводы. Нет чтения flight store, личных перелётов, времени сборки или аналитики. Изменения CSS и JS интерактивности не пытаемся выдавать за содержательные изменения SEO-текста.
- Sitemap discovery при пустом catalogue работает также у worker. Если discovery не удался, действующая очередь продолжает обработку. Далее прежний daily; dry не обращается в сеть и не сохраняет состояние.
- Убрано EN→12 размножение: sitemap уже перечисляет настоящие локализованные canonical URL. RU/EN legal сохраняются, fallback/noindex других языков не получают новых заданий.
- Фильтр семейств исключает личные страницы, API, flight/airline, alias departures и неподдерживаемые типы. Это статический допуск, не универсальная проверка runtime robots. Конкретные generic URL поступают из sitemap; удаление из sitemap само по себе не стирает историю.
- Очищаются только неподдерживаемые производные pending-задания, sent/fingerprints/runs остаются. Поддерживаемые backoff, приоритеты, SHA публикации, flock, сохранение и fallback транспорта не меняются.
- Сохраняются партии ≤50 и ≤100 URL за запуск. Это лимит запуска, не отдельный суточный лимит. После применения новые семейства догоняются существующей очередью, без массового ручного обхода.
