# Расширение справочников: условия публикации

Поручение09.11: максимально улучшить аэропорты на всех языках, особенно проверить переводы.
Инвентаризация — inventory.json. Не считать наличие JSON доказательством качества.

Каждая партия проходит:
1. Проверка источника каждого нового/изменённого утверждения; сохранённый URL,
   дата и фрагмент. Тариф, срок, зона, доступ, отрицание проверяются отдельно.
   Для HRG/SSH два разных независимых домена согласно CLAUDE.md.
2. Русский оригинал без двусмысленностей. Не разрешать противоречие переводом.
   Gate/exit, landside/airside, сутки/день, до/включительно фиксировать явно.
3. Перевод11локалей. Сохранить названия и обозначения на указателях;
   не переносить грамматические категории русского буквально.
4. Независимая от автора сверка каждого изменённого title/hint/text/about.
   Записывать просмотренные файлы, конкретные замечания и принятое решение.
   Автор исправления не объявляет собственный текст независимо проверенным.
   Рецензия агентом не является проверкой носителем языка.
5. Повторная сверка исправлений. Финальный diff должен соответствовать отчёту;
   изменение после рецензии требует повторной проверки изменённого поля.
6. Автоматика: полный комплект файлов и блоков, about, числа, посторонние
   алфавиты, лимиты подсказок, JSON, сборка/типы. Отрицательные контрольные
   примеры доказывают, что проверки действительно ловят пропуски/подмены.
   Эти тесты не доказывают смысловой эквивалентности.
7. HTML и FAQ дословно совпадают на всех12локалях; canonical/H1/indexability.
   Узкий экран: каждую локаль смотреть отдельно, раскрыть изменённые карточки,
   проверить обрезание/перекрытия/RTL. Не называть эмуляцию физическим телефоном.
8. Публиковать только прошедшую партию; CI, SHA трёх процессов и повторная
   проверка публичного HTML после обновления ISR. Production толькоaudit-bot.

Новые аэропорты без надёжных источников остаются в очереди. Массовое наполнение
шаблонным текстом, новые тарифы по памяти, выдуманные услуги не допускаются.
Эффект SEO оценивается отдельно; рост индекса/AdSense не является гарантией.
