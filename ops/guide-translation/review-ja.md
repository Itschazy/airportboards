# Рецензия перевода справочной — ja

Проверено: все 76 файлов `data/airport-guide/ja/` против `data/airport-guide/<IATA>.json`, каждый блок и `about`
(смысл, числа, имена, стиль; заголовки, длина hint). Структура: у всех 76 файлов верный `iata`, полный набор блоков,
`about` есть ровно там, где в оригинале; каждый файл — японский текст целиком (непереведённых/чужих блоков нет).
Кириллица — только в кодах маршрутов и зон (111Э, 105с, Т1, 3Б и т. п.), как требует BRIEF.
Итог `node scripts/check-guide-fresh.mjs`: по ja провалов нет (ja 76/76).

Правок 64 в 39 файлах: смысл 7, числа 21, имена 16, стиль 20.

Решения, принятые единообразно:
- «первые сутки» → 最初の24時間 (а не 最初の1日 / 初日); «каждые следующие сутки» → 以降24時間ごとに. Оставлено
  最初の1日 там, где оригинал сам привязывает сутки к календарю: MRV «(до 24:00)», NBC «(до 23:59 дня сдачи)», SGC «(до 00:00)».
- «в сутки» в ценах оставлено как 1日 там, где проверка это принимает; где переводчик писал 一日 (проверка не пускает
  цифру 1, если её нет в оригинале), заменено на 24時間 для парковок и камер хранения; у гостиниц (NOZ) 一日 оставлено.
- 一人 / 大人一人 оставлено: это нормальная японская запись, цифра 1 там проверкой не принимается.
- Имена операторов, переведённые на английский («… Airport社», «LLC»), транслитерированы; японские описательные
  формы (ソチ国際空港社, イルクーツク国際空港社) и официальная латинская форма Airports of Regions, Ramport Aero оставлены.
- «более N» → Nを超える / N超 (以上 включает само N).
- VOG: в оригинале терминал «С» кириллицей, в переводе латинская C — оставлено, иначе проверка ловит одиночную кириллицу.
