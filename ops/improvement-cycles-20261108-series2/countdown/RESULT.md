# Стабильная высота статуса при запуске отсчёта

Репродукция: production-сборка на синтетической фикстуре, пустой Airlabs key;
Chromium IAB на Mac, 375×812. HTML проходит loopback proxy с ранними
PerformanceObserver и MutationObserver. Сервер и прокси только локальные.
По три загрузки до/после, один браузер, viewport, хранилище и тот же порядок.
Ресурсы прогреты; CPU/network throttle отсутствует. Это не физический Android.

До: CLS 0.0203298756 во всех трёх загрузках. После: 0.0019508460,
0.0006126838, 0.0019663892; медиана 0.0019508460 (снижение примерно на 90.4%).
Основной layout-shift совпадает со сменой двух первых подписей «По расписанию»
на «Через N мин». Высота frow-what падает с 56.59 до 41.64 px.
Номер минуты менялся с течением реального времени, в обоих проходах два
двузначных отсчёта; время не подменялось и фикстура не перегенерировалась.
Абсолютный LCP здесь не измеряет холодную сеть телефона: ускорение LCP не заявляем.

check.mjs before.json → exit 1; check.mjs after.json → exit 0.
Это проверка записанных браузерных измерений, не самостоятельный запуск браузера.
Полный probe/proxy/browser.jsonl и screenshot — в outputs/.../cycle1.

Причина уже локализована в cycle8 прошлой серии и подтверждена свежей
репродукцией. Гипотезы: 1) более короткая подпись уменьшает колонку — резерв
исходного текста уберёт этот источник сдвига; 2) шрифт — тот же резерв не
поможет; 3) content-visibility — первый экран с visible останется нестабилен.
Менялся только первый фактор: естественная высота спокойного текста сохранена
невидимым CSS-псевдоэлементом в той же grid-ячейке. Ни фиксированных высот, ни
нового видимого текста, ни запечённых часов ISR. Остаточный малый CLS не объявлен нулём.

12 локалей на 320 и 375 px: горизонтального overflow нет; у остальных 11 языков
высота первых статусов не меняется, RU375 сохраняет SSR-высоту. Карточки открыты
и закрыты на 12 языках, фокус возвращается на строку. Русская «Показать больше»
реальным pointer-кликом раскрыла 30→80 строк без модального окна. Console errors0.
Это mouse/keyboard на Mac, не физический touch/Safari. Псевдоэлемент visibility:hidden
отсутствует в наблюдаемом accessibility tree; голосовой screen reader не запускался.

Проверки: две fixture-сборки по2473 страницы; TypeScript;12×395 ключей;
check-scripts (232148 строк/8351 файл), client-messages, board logic/regressions,
board-interactions, board-intent17, flight-time20, recent-history/recent-locales,
search-race. На localhost: index20/20, sitemap-hreflang, live-refresh, adsense,
first-paint (CSS11424B gzip), flight-map — exit0. Начальный вызов flight-map без
base дал ECONNREFUSED3111; исправлен адрес на работающий3187, повтор прошёл.

Изменены только CSS и обёртка статуса FlightBoard; подписей, схемы, метаданных,
часов, API, данных и языковых ключей не меняли. Перед публикацией нужны свежий
main/разрешённое окно; после — успешныйCI,серверныйSHA и4production-сторожа.
