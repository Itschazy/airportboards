## Кто пользуется (Метрика 110112198, 30 дней до 18.10)

- Живая аудитория — **~27 тыс. визитов/мес из Яндекса, ~90% смартфоны**, отказы ~11%, ~3.5 мин.
- **25 тыс. «прямых» визитов с ПК — боты** (отказы 94%, 11 с). Ферма headless-браузеров из
  Tencent Cloud 43.172.0.0/15 закрыта на nginx 18.10. В Метрике 18.10 включён фильтр роботов
  «по правилам и поведению» (`filter_robots: 2`). **Любые решения по UX — только по сегменту
  «смартфоны из поиска»**, иначе меряешь шум.
- Ищут табло курортов и своих городов: Хургада, Шарм-эш-Шейх, Анталья, Баку, Бодрум, Даламан,
  Гюмри, Уфа, Казань, Толмачёво, Домодедово. Формулировки: «онлайн табло вылета/прилёта»,
  «на сегодня». Много «прилёта» — это встречающие.

## Сделано 18.10.2026 (Claude)

Инфраструктура и деньги — см. раздел «Сервер» в CLAUDE.md:
- переезд FirstVDS → Timeweb Cloud, nginx-микрокэш 30 с, pm2 cluster, хранилище для нескольких
  процессов (`lib/flightStore.ts`), `/api/health`, блок фермы Tencent;
- `e194e9cb` — живая покупка с `/api/flights` отказывала КАЖДОМУ читателю как «localhost»
  (за nginx `req.nextUrl.hostname` = localhost). Хост теперь из заголовков;
- `d3b413b1` — свежесть для читателя на ЛЮБОМ аэропорту: старше 10 мин — докупаем при заходе,
  моложе — бесплатно из хранилища. Пока едет ответ — подпись «Обновляем…» (`ui.updating_now`).
  Проверено по архиву покупок: повторных покупок одного борта раньше 10 мин — 0.

UX (план, этап 1):
- `9b86b6ca` — **«Поделиться рейсом»** в карточке рейса (системное меню / копирование ссылки с
  запасными путями) и **открытие рейса по ссылке** `?flight=КОД&dir=arrivals|departures`;
  статус «По расписанию/Вовремя» в строке — обычным регистром в одну строку, тревожные статусы
  — заглавными; пороги шрифта города сдвинуты (`cityFs`).
- `4289bfbb` — фикстура пишет время как airlabs («YYYY-MM-DD HH:MM»), иначе локально пустая
  колонка времени. Остаётся артефакт: время фикстуры в UTC, а не в местном поясе аэропорта.

### Отложено осознанно
- Вес страницы: HTML ~300 КБ, по сети 41 КБ gzip — для мобильных приемлемо. Основной вес —
  инлайн-стили, продублированные в RSC-полезной нагрузке; лечится переносом стилей в CSS,
  большая работа ради умеренного выигрыша.
- Общий rate-limit на `?_rsc=` по IP: ферма Tencent шла с 1 497 адресов по ~12 запросов, лимит на
  адрес её бы не остановил. Если появится новая ферма — смотреть подсеть/ASN в
  `/var/log/nginx/access.log` и закрывать в `/etc/nginx/conf.d/airportsboard-deny.conf`.

## Как проверять

- Интерфейс — локально на 375 px (см. AGENTS.md, п. 3), снимки до/после.
- Прод после выката: `node scripts/check-index.mjs`, `node scripts/check-sitemap-hreflang.mjs
  https://airportsboard.live`, `node scripts/check-live-refresh.mjs`, `node scripts/check-adsense.mjs`.
- Живая покупка: на сервере `curl "localhost:3000/api/airlabs-usage?token=$(grep ^CRON_TOKEN= ~deploy/airportsboard.env | cut -d= -f2-)"`
  — `liveBudget.admitted` должен расти, `refused.localhost` — 0.
- Эффект UX — Метрика, сегмент «смартфоны из поиска»: отказы, время, доля возвратов.
  События `lib/track.ts` (`flight_card`, `board_mode`, `board_filter`, `board_more`, `search_pick`,
  `flight_share` — с 18.10) отправляются, **но целей в Метрике не заведено ни одной** (API
  `management/v1/counter/110112198/goals` пуст). Завести цели «JavaScript-событие» с этими
  идентификаторами — согласовать с владельцем, это настройка его аккаунта.
